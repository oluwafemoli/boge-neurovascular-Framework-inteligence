# BOGE Neurovascular Framework Intelligence — Website Template

Static multi-page academic research website template built for [`oluwafemoli/boge-neurovascular-Framework-inteligence`](https://github.com/oluwafemoli/boge-neurovascular-Framework-inteligence).

## Folder Structure

```text
boge-neurovascular-website/
├── index.html              # Lab overview & architecture landing page
├── research.html           # Research pillars & computational methodology
├── resources.html          # Interactive module directory, inspector modal & BibTeX box
├── README.md               # Setup and GitHub Pages deployment guide
└── assets/
    ├── css/
    │   └── styles.css      # Academic slate/teal design system & responsive layout
    └── js/
        └── app.js          # Module catalog data, live search/filter & modal logic
```

## Deploying to GitHub Pages

1. Extract this archive into your repository (either at the root or inside a `/docs` folder).
2. Open **Settings → Pages** in your GitHub repository.
3. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)` (or `/docs`), and click **Save**.
