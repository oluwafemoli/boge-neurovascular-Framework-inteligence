Quickstart Installation & Usage

Get started with the Boge Neurovascular Framework Intelligence python package in seconds.

terminal / python3 
# 1. Install via pip from GitHub repository
pip install git+https://github.com/oluwafemoli/boge-neurovascular-Framework-inteligence.git

# 2. Import core framework and simulate hemodynamic response
from boge_neurovascular import NeurovascularModel, SimulationEngine

# Initialize model with standard physiological parameters
model = NeurovascularModel(tau_s=2.5, alpha=0.38, epsilon=0.82)

# Run temporal simulation over 30 seconds at 1000Hz sampling
results = SimulationEngine.run(model, stimulus_duration=5.0, total_time=30.0, dt=0.001)

# Export BOLD coupling waveform
results.to_csv("boge_simulation_output.csv")
print("Simulation complete. BOLD peak amplitude:", results.max_bold())
